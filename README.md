Epic! *(aptly named after the Explicitly Parallel Instruction Computing architecture)* is an emulator that faithfully emulates multiple generations of the Intel Itanium family accurate to their real-hardware counterparts.

## Introduction
### What is Epic?
As stated above, Epic! is an Itanium emulator that aims to **accurately** emulate various Itanium processors and machines and their underlying hardware. It aims to provide an environment that allows different operating systems and applications built for the Itanium architecture to run on modern machines.
### What does Epic! aim to emulate?
Epic! aims to support multiple generations and configurations of Itanium-based systems, including:
| Machine  | Description |
|-------|-----|
| Intel Itanium Software Development Vehicle (SDV) | A platform designed to support the development and testing of software for the Itanium architecture. |
| HP Workstation i2000 | HP’s first Itanium-based workstation, introduced in 2001 for developing and running various Itanium software. |
| HP Workstation zx2000 | An early-2000s workstation built around a 900 MHz Intel Itanium 2 processor and HP’s zx1 chipset. |
| HP Integrity rx2660 Server | A mid-range server primarily designed for HP-UX and OpenVMS. |

*Note that Epic! is currently in its pre-release stages and certain machines may be tweaked, added, or removed.*
### Project Status
Epic! is currently in **active development**, and as such, what you're seeing here is not the final product and certain parts of the emulator **will** change. It is not recommended to use the emulator when it comes to tackling heavy workloads and/or as a replacement for real Itanium hardware, as some functionality may be buggy, incomplete, unstable, or outright missing.

### Source Availability
Epic! is a closed-source project in its entirety. However, selected smaller components and some portions of the project may be released publicly in the future.

These releases are intended to assist with research, documentation, and the broader understanding of the Itanium architecture and its associated hardware.
